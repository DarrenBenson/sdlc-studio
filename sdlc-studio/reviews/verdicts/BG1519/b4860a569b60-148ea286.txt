ISSUES: [regression] The count floor reads pytest's summary as plain text, so a run in which a test passed is refused as "0 tests ran" whenever pytest colours its output or prints no summary line. `_PYTEST_COUNT` (gate.py:879) needs a word boundary before the digit, and under forced colour the line reads `\x1b[1m1 passed`, so `m1` has no boundary and nothing parses. The plan's own `-q` (gate.py:2802) plus a project's `addopts = -q` or `PYTEST_ADDOPTS=-q` makes `-qq`, which drops the summary line altogether. Each phase then reads None, and `count_floor` returns "0 tests ran by any count pytest printed: no phase ended on a summary line" (gate.py:911). Tried by execution on a fixture holding one passing module, `def test_ok(): assert True`.
