## Summary

Commit 245513c9 (the RUN-01M0ATVZ close) renamed `test_the_corpus_census_moves_by_exactly_four` to `test_the_corpus_census_stays_within_its_measured_bounds` in test_file_finding.py and left BG0585 AC6's `Verify:` line naming the old node. The write-time guard (CR0508) refuses a selector that resolves to nothing when the LINE is written; nothing checks the corpus when the TEST moves, so a rename in a test file passes every per-commit lane. The only reader is the scheduled `corpus-verify` lane, whose stamp half now reports `dead-stamps: 4, baseline 3 - 1 NEW`, and it has failed on 24 August, 31 August and 7 September with nobody reading it. Because `verify-corpus.sh full` runs the stamp half first, the red-criteria count the v5.1 stale-selector sweep is ruled against (D0137, D0142) has not been re-measured since 12 August either. LL0047 named this shape: a verifier the staleness sweep cannot resolve is one whose test can vanish unnoticed.

## Steps to Reproduce

1. `bash tools/verify-corpus.sh stamps` on 2c6ffef2 - prints `corpus-verify FAILED: dead-stamps: 4, baseline 3 - 1 NEW one(s)`.
2. `python3 .claude/skills/sdlc-studio/scripts/verify_ac.py stamps --root . --bugs` - names BG0585 AC6 and the selector `...::test_the_corpus_census_moves_by_exactly_four`.
3. `git log -S test_the_corpus_census_moves_by_exactly_four -- .claude/skills/sdlc-studio/scripts/tests/test_file_finding.py` - the node was renamed at 245513c9.
4. `gh run list --workflow lint.yml --event schedule --limit 3` - three consecutive failures since the rename, none acknowledged; the run of 17 August was also red, before the rename, for a cause not established here.

## Proposed Fix

Two halves. Repoint BG0585 AC6 at the renamed node so the stamp count returns to the baseline of 3 (the baseline is not raised). Then add a per-commit lane, `stamps-staged`: `verify_ac.py stamps --staged` (or `--files <paths>`) reads only the test files the commit stages as modified, renamed or deleted, finds every stamped criterion in the corpus whose selector names one of them, and refuses when a selector no longer resolves, naming the artefact, the criterion and the selector. A commit staging no test file is silent and costs no corpus sweep. AGENTS.md's lane roster and tools/tests/test_check_spec_claims.py's pin gain the lane (LL0013).
