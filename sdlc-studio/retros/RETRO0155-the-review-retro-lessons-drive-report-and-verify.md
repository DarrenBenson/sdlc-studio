## Keep

- Fixing a stale page inside the unit before it lands. Lane C2's builder named help/review.md and reference-review.md as made false by BG1125 and BG1265; widening those units' Affects and having the builder correct both pages before the land cost two short follow-ups instead of two rejected rounds.
- Reading a builder's hand-back for an admitted regression before landing. RP2 said a variable named `io` calling `.open('w')` was no longer named by the sweep; sending it back before the land closed a [regression] that would have rejected BG1532 in its last round.
- The diff-coverage pass in the builder prompt. Lanes built with it (RC2, RD, RV3, RC3, RR2) converged in fewer rounds than the first builds, which rejected 8 of 8 (R) and 3 of 3 (D).
- One ruled round past the cap where a single test or sentence was left (D0579 to D0586, D0588 to D0591), and one repair lane per shared file.

## Stop

- Stop waiting on another job with `pgrep -f`. A loop matched its own shell twice: once on a bare pattern, and once on a `[c]`-bracketed pattern whose command line also held the literal script name in a `sed`. RR2's close sat for about 40 minutes and two later jobs queued behind it.
- Stop keeping agent state under a shared name in the session scratchpad. A reviewer kept its worktree path in a scratchpad file another agent overwrote, so its mutation run wrote into a second reviewer's worktree for a minute (22:54 to 22:55 UTC); the second reviewer threw away and re-ran every result from that window.
- Stop committing locally through the hooks while builders and reviewers load the workstation. At load 20 on 8 cores, lane P's commit hit its 55-minute bound twice and passed on a fourth try with a 7,000-second bound, and timing tests (test_sprint_drive_wave, RealTreeMarkerTests, a kill-grace test) failed commits that then passed on retry.

## Try

- Serialise landings and run-state writers with a lock file (flock) held by `lane land` and `lane accept`, so an orchestrator never polls for another job.
- Have `critic.py brief` and `sprint.py lane brief` issue each agent its own scratch directory and name it in the brief, so no two agents share a state file.
- Deliver CR0663 (run the commit-time suites on the gate host, as the push already does) in the next run, so a local commit does not compete with the agents for the workstation.

## Cost

- The cause is repair rounds again, and commit retries under load. Most first reviews rejected on [new] lines in the unit's own diff (D0561), 13 units needed a ruled third round, and each repair round paid for a builder and a reviewer again.
- Lane P was committed four times (two timeouts at the commit bound under load, one timing-test failure, one pass) and RC2 twice; lane C2's BG1700 fix was needed before any push could pass, because `critic.py show` had passed the boundary test's 120-second limit even on the idle gate host.
- About an hour of elapsed time went to the stuck wait loop and the contaminated review window.
