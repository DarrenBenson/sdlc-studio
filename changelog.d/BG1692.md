`sprint close` now rules an open bug that declares `> **Falsifies:** <goal clause>` in its header
as blocking the goal claim. The close's open-defect reader carries the field's text, when it is
present and not empty, to the goal judgement, which prints `BLOCKS THE GOAL CLAIM <id>:
falsifies the goal clause: <clause>` and writes a `blocks the goal claim` row to the report; the
close still does not refuse on it. Before, no defect the close read ever carried that field, so
such a bug was ruled leavable whatever its header said. Only bugs at Open or In Progress are
read. The judgement's docstring no longer says a defect blocks for naming a clause, which no
code checks, and reference-bug.md names the optional field.
