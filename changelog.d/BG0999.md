The caller check (`critic.py caller-check`, and the line `sprint close` prints from it) now
resolves a Caller naming a script of the loaded skill by its file name, such as `decisions.py
waive`, in a project whose own tree does not hold that script. Only a path-shaped token, one
carrying a dot or a separator, is looked up there, by file name, so a bare word or a stem still
never resolves against the skill, and a name found in neither tree is still reported unresolved.
