The finding filer escapes a bare ` ** ` standing alone between spaces in a title, summary, steps, fix, evidence or criterion (`\*\*`), so markdownlint no longer refuses the bug file and its index row (MD037). A real `**bold**` pair, a `**Field:**` declaration, a marker in a code span and a fenced block in the steps are written as given.
