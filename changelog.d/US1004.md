- CI installs the suite's Python packages from `requirements-dev.txt`, the same file
  `tools/gate_prereqs.py` checks a clone against.
  - **What a test holds.** Every `pip install` in the ci job must name that file as its only
    requirements file, or install only a named tool that is not a suite package. That covers
    any spelling pip accepts. The file itself includes no other.
  - **Corpus-verify.** The scheduled corpus-verify job keeps its own shorter list, held to a
    subset of the file with no looser floor.
