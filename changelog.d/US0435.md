- **A sprint close whose outstanding set is GROWING now offers the bounded exit, not only the diagnosis (US0435, EP0162).** The close already recorded each attempt's outstanding count and named a growing set as "chasing a moving target", but named no way out - so a close that re-broke one lane while fixing another left only the moves the gate exists to stop: a forced false Done, or a grandfather bump. When the count rises across consecutive attempts the trend line now also names `--file-and-close --retro <id>` as the way to complete the close with the remaining work filed as linked follow-ups, honestly recorded as outstanding rather than waived. The offer is made only when growing, never on a first or converging attempt, so it does not train an operator to reach for it on a close that is working.
