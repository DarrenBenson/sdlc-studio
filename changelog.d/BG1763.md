A lane brief no longer asks a project whose tests pytest cannot run, such as vitest's
`*.test.ts`, to list its mutants with pytest selectors for the mutation runner, which runs
pytest alone. When none of a unit's Affects test files is a `.py` file, the author self-check's
mutation pass now tells the builder to run each mutant by hand with the project's own test
runner and list it in the unit's mutants file (`MUTANTS.json`, or `<unit>-mutants.json` in a
lane brief), and names no pytest selector, `EDITS.json` or runner command. A unit with both
kinds of test file keeps the runner route and is told which of its test files pytest cannot
run. A pytest unit's brief is unchanged.
