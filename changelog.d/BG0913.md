- Re-running `sprint close` on a run that already filed its page no longer moves the page's
  window end or takes a new main-thread meter reading. The first close that files a page records
  its window end on the run, and every re-close re-derives against it, so work done after that
  close (corrections, paperwork) no longer counts as the run's minutes or tokens; only artefact
  changes move a re-filed page. A close whose page was refused fixes nothing (BG0913).
