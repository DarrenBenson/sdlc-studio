<!-- section: Changed -->

A run closed and awaiting its signature no longer holds the run slot (US1290, D0503). `sprint plan
--write` names each waiting run and opens the next one, in a fresh clone or in the checkout that
closed it, leaving the waiting record untouched; a run open and not yet closed still refuses a
disjoint batch. `sprint sign` seals a waiting run while a later run is open, setting the open run's
state aside and putting it back byte for byte. `status.py` names every run awaiting its signature,
and the evidence schema's awaiting rule says the plan no longer refuses on it.
