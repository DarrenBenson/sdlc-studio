A harness compatibility page, `docs/harnesses.md`, shows what SDLC Studio gives in Claude Code,
Codex, Cursor, Gemini CLI, GitHub Copilot and opencode: install path, invocation, skill
discovery, parallel or sub-agents, token and cost reporting, hooks and gates, and live reload.
Each cell names the file in this repository that shows it, or says untested. A fallbacks table
says what a harness without a feature does instead; for `epic implement --agentic` that is plain
`epic implement`, the same stories one at a time in dependency order through the same gates. A
new test reads the install paths from `install.sh` and `install.ps1`, checks that every source a
matrix cell names exists, and fails on a feature with no fallback. (US1316)
