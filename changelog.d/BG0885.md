- `critic.py record` escapes an opening bracket that follows `]` or `)` in a verdict cell, so
  a finding quoting a regex (`[A-Z][A-Z_]{4,}`) or a reversed link (`(state)[2]`) no longer
  makes markdownlint refuse `critic-verdicts.md` (MD052, MD011). The ledger's readers undo the
  escape, so `parse_findings` returns each finding as the reviewer wrote it, underscores
  included.
