Each change in a release's evidence pack lists the known issues its signed report hands over that
name it, or "none recorded", and the pack carries the issues that name no change in one
release-level list. Each change names its report's signing principal, with the signing date, as
the accountable person; a blank or agent principal refuses the pack and nothing is written.
A principal reads as an agent when it holds the word agent anywhere (`sub-agent`, `an AI agent`)
or when the committed verdict or self-check ledger records it as an author, such as a builder's
model name; a typed human author is not counted.
