A file path in finding or request prose is written as one code span, where it used to come out split into prose and a code-spanned file name: a relative path (`tools/tests/test_x.py`), a rooted one (`/abs/dir/test_x.py`, `~/.cache/run_x.json`, `$HOME/bin/do_it`) and one whose underscore sits in a directory (`src/my_pkg/main.py`). The escaper reads a path in a single linear pass, so a very long run of segments costs no more than any other prose. A bare identifier is still wrapped, a path already in a code span is unchanged, and a path with no underscore inside a word (`docs/guide.md`, `sdlc-studio/bugs/_index.md`) is left as written.
