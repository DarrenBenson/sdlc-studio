A file path with a directory in finding or request prose (`tools/tests/test_x.py`) is written as one code span, where it used to come out as the directory followed by a code-spanned file name. The finding filer's prose escaper takes the directories before an underscored name as part of the path, and `artifact.py new` writes the same prose through it. A bare identifier is still wrapped and a path already in a code span is unchanged.
