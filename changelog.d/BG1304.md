A file path in finding or request prose is written as one code span, where it used to come out split into prose and a code-spanned file name: a relative path (`tools/tests/test_x.py`), a rooted one with one or more segments after its root (`/abs/dir/test_x.py`, `/tmp_dir`, `~/my_file.txt`, `~/.cache/run_x.json`, `$HOME/bin/do_it`) and one whose underscore sits in a directory (`src/my_pkg/main.py`). The escaper reads a path in a single linear pass, so a very long run of segments costs no more than any other prose. A bare identifier is still wrapped, a path already in a code span is unchanged, a path with no underscore inside a word (`docs/guide.md`, `~/plain.txt`, `sdlc-studio/bugs/_index.md`) is left as written, and a slash after a call or an index (`unit_cost()/attempts_of`) is two identifiers, each in its own span, never one rooted path.
