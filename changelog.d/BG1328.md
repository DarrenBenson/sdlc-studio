Minting a story into an epic that is Done reopens the epic to In Progress, and moves the request it delivers back to its working status when that reads terminal, so `reconcile apply` no longer derives the request Complete over a Draft story. `refine.py apply --request <request> --into <epic>` now adds a further slice to an epic the request already names: the request lists the epic once, a Done epic is reopened, and `--into` an epic the request does not name is refused as before.
