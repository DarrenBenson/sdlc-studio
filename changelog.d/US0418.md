- **A writer's `--fields-file` can carry metadata as well as prose (US0418, EP0156).**
  `resolve_prose_fields` gains a `prose_keys` argument: `allowed` now names every field the writer
  accepts - prose and metadata - so one committed, re-runnable document is the whole invocation,
  while the shell-hazard check covers only the prose subset (the fields a shell can actually
  mangle). An unknown key is still refused by name, and a caller that passes no `prose_keys` is
  unchanged - the whole allowed set is treated as prose, exactly as before.
