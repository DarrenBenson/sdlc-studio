The evidence page now has a Model column (US1321). `sprint_report.py evidence` reads it from each
signed report's own JSON: each `price_model` of its `cost_prices` rows or, where it priced none,
each `model_name` of its tokens-by-model rows that names a model rather than mixed or unrecorded.
A report naming neither reads not recorded, and the catalogue of prices a report carries is never
read as a model it priced. `docs/evidence.md` is regenerated through RPT0035, run sixteen's report,
and says the reports do not yet record the harness each run ran in, which CR0743 adds; its
committed-page test fails on a page older than RPT0035 or one that leaves the harness gap unstated.
