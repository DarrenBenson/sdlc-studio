The author self-check section of `critic.py brief` no longer prints the words of a `-k` or
`-m` expression as pytest selectors. It names the files, directories and node ids a Verify
line selects, and the expression by name as one that names no test. The value of an option
pytest itself or pytest-xdist reads one for, such as `-p no:cacheprovider`, `-r a` or
`--deselect <id>`, is not named either, and a cluster of short flags such as
`-qk 'add or sign'` is read as pytest reads it, as `-q -k 'add or sign'`. A value joined
to its option by `=` is read as pytest reads it too: `-k=add` is named as the expression
`add`, not `=add`, and `--deselect=<id>` leaves the next word a target. `critic.py
self-check record` writes the kept mutant list before it adds the row, so a list that cannot
be written refuses the record with no row added, and a row that cannot be added leaves the
list as it was. A malformed kept list is refused with an error naming the file, where the
brief used to crash. The kept list names the runner's report by its path relative to the
project root, or by its name alone when it lies outside, never by an absolute local path.
