The PRD's Environment Variables table (BG1553) lists every variable the shipped scripts read through an environment `get`, a subscript, an `in` test, an `_ENV` constant or a harness signal table, including `SDLC_STUDIO_HARNESS`, `CURSOR_API_KEY`, `SDLC_STUDIO_CURSOR_AGENT_ID` and `SDLC_STUDIO_CURSOR_API`, marks the API key as a secret and the second as a network endpoint override, and says the harness sets `CLAUDE_SKILL_DIR` and no script reads it. A test collects the names from the scripts, so a variable without a row, or a row for one nothing reads, is named.
