- `sprint close` no longer refuses a run whose units are all independently approved because one
  of them carries a REJECT in the frozen pre-6.x batch review ledger. The closing-review row now
  reads each unit's latest verdict across both ledgers, by date: a per-unit APPROVE recorded after
  a frozen batch REJECT clears the unit, a REJECT recorded later than an APPROVE still holds it
  whichever ledger records it, and a same-day tie between the ledgers holds the unit.
