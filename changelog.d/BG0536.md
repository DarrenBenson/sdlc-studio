- **A test fixture can no longer address the working tree (BG0536).** A helper that built its
  scratch repo under whatever root it was handed was called once with `"."`, so the test wrote
  into the real repository on every run - including the gitignored mutation ledger the terminal
  transition gate reads, destroying 23 recorded registrations across five delivered units. Git
  could not restore them because the file is ignored; they were re-recorded and re-verified.
  The helper now refuses any root outside the temp directory. The defect was not the bad call:
  a fixture whose root is a parameter will eventually be given the wrong one, and writing to a
  real path looks exactly like writing to a temp path until somebody checks what changed.
