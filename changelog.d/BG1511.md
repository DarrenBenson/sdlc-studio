The skill's own tests no longer leave a module they swapped in `sys.modules` behind. A test
that loaded a script under its own name and registered it there kept the copy for every later
test in the process, the shape that read red only in the batched release gate. Each test-time
swap in the test tree now sits under a `mock.patch.dict(sys.modules)` that is stopped on
cleanup, and a new hygiene test scans every test module for an assignment to `sys.modules`
that nothing restores (no `patch.dict`, `addCleanup` or restoring `finally`), reporting it by
file and line. A registration made at import time is counted as advisory and does not fail it.
