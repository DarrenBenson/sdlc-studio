### BG0628

**The conformance figure was a fact about the tree, not about the corpus.** `verified` is unmet
when a unit's stamped verifiers do not resolve, and `selector_resolves`returned`False` in two
situations with opposite remedies: a test file that EXISTS and will not collect - real debt, fix
the test - and a test file the tree does not hold at all, where there is nothing to fix and the
reading is simply unavailable.

So the same 814 units scored 304, 671 or 732 conformant depending only on which directories had
been copied, and nothing in the output said which reading you were looking at. The summary went
on to recommend `backfill` and an adoption cutoff, which are the right advice for debt and
useless for an incomplete checkout.

The readers most exposed were the ones following this project's own doctrine. Every adversarial
reviewer is instructed to copy the tree before running anything, so the wrong reading is the one
an independent reviewer is told to produce. Two did in one session and both reported it as fact;
a third figure then had to be defended by re-measuring.

**What changed.** `selector_resolves`returns`None` - unanswerable - when the selector's test
file is not in the tree, and keeps returning `False` when the file is present and will not
collect. `unevaluable_stamps`names those stamps, deliberately disjoint from`unresolvable_stamps`so nothing is counted twice.`conformance` collects them in their own
bucket, keeps them out of the non-conformant count, and prints a line naming how many units and
which files are absent - before any verdict, for the same reason `scope_detail` is printed there.

Measured on this repository: a complete tree and a `sdlc-studio/`-only copy now both report
**725/814 conformant, 7 not**, where the second previously collapsed. The partial tree names its
496 unevaluable units instead of scoring them as debt.

The exit code deliberately does not change here. BG0628 records that whether an unevaluable tree
should exit 0 or take a distinct third code is a decision to make rather than a defect to fix;
what had to stop was scoring it silently as debt.
