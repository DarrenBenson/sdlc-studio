`routing.effort` now takes an entry per kind of unit, `docs`, `bug` and `code`, beside `builder`
and `reviewer`: each entry maps a role to an effort, and a role it leaves out takes the role
default. A unit is a bug by its id, else code when an Affects path ends in a code extension, else
docs, as `route.work_kind` classifies it. With any entry set, `sprint plan` stamps each unit's
own effort with its `kind`, and `sprint lane brief` names that effort and kind for the unit it
briefs. `sprint plan` exits 2 before it selects or writes anything on an unknown kind, a role
other than `builder` or `reviewer` in an entry, or an unknown effort, naming the key and what it
takes, and refuses a reviewer below its builder within a kind unless
`routing.effort.reviewer_below_builder` names a decision `decisions.md` records, printing that id
and the kind when it plans. The entries ship empty, so a project that sets none plans and briefs
exactly as before.
