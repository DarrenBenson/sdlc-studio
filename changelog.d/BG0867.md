- A status transition keeps a padded index table lint-clean. `transition.py set` (through
  `reconcile` apply) wrote the synced row compact beneath a header and separator padded to
  aligned widths, so markdownlint failed MD060 on the index and the next commit was refused.
  A new `sdlc_md.align_padded_tables` re-aligns each table written in the aligned style around
  the rows apply rewrote or appended, widening a column for a value that no longer fits and never
  narrowing one; compact tables, fenced examples, escaped pipes and `:` alignment markers are
  left as written (BG0867).
