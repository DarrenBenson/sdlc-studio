The validator no longer warns pseudo-verify on the `- **Verify:**` line indented beneath a request's criterion, the line `file_finding.py file --type cr --verify` writes there. Only a command in the criterion's own prose is judged, as the filer's refusal judges it, and the warning now advises keeping the command on a `- **Verify:**` line beneath the criterion. A `- **Verify:**` item flush with the margin, or one with no criterion above it, is still warned.
