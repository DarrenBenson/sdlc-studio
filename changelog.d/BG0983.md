Review coverage now reads only the open run's own review of a unit. `critic.verdict_for`, which
`sprint.review_coverage`, the close's closing-review row and the seal's bar all read, takes a unit
the open run holds from its rows past the run's `REVIEW_BASE`, as `critic.delivery_rounds` counts
its rounds, and reads no verdict for a unit the run holds and has not yet reviewed. An APPROVE an
earlier delivery recorded therefore no longer covers a reopened bug or a story moved back into a
later run, and the close's closing-review row reads not run until the run reviews it. An APPROVE
recorded in the run still covers the unit, and outside a run, in a run that has ended, for a
unit no open run holds, or with a run state that cannot be read, the whole ledger is read as
before. (BG0983)
