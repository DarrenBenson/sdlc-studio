The commit-msg hook's trailer derivation and the multi-id subject check now find git's scissors
line under any comment character (`core.commentChar` set to `;`, `@` and so on), not only `#`. They
read nothing below it, so a `Refs:` context line in a verbose commit's diff no longer accounts for
a subject id, and the derived trailers are written above git's comment scaffolding in that
character. The unnamed-unit note reads only the author's text as well. The `_ledger_rows`
docstring now says a review-ledger row the commit adds or edits makes its unit the ledger's owner.
