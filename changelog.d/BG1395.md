<!-- section: Changed -->

- `verify_ac.py run` and `verify_ac.py report` count partial skips apart from other failures.
  A criterion whose pytest target ran only in part is still counted in `fail=`, and each
  story's line now also carries `partly_skipped=N`. A closing `total:` line, new to `run`,
  gives the same count beside the run's `fail=` and names each partly skipped criterion, so a
  release gate can say how many of its reds ran only in part. An all-skipped target keeps its
  own all-skipped verdict and is not counted as a partial skip. The verify report records the
  count on each story and a `partly_skipped` flag on each failure.
