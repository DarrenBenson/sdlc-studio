`critic.py record` now writes a bare email address (`ops@example.com`) or a bare `www.` address
in a finding as a code span, as it already did a bare http(s) URL, so the verdict ledger passes
markdownlint's MD034 (no bare URLs) at the next commit that touches it. A trailing full stop or an
unbalanced closing bracket stays outside the span. An address already in a code span, in angle
brackets or in a link destination, and a `www.` inside a longer host name, are written as given.
