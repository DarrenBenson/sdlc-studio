The self-check gate in `critic.py brief` now reads a merge commit by its combined diff, so an edit
the author made while resolving a merge conflict in a declared file stales the record under
`review.author_self_check: block`, as any other edit of the author's does. A merge is attributed
by its subject like any other commit, and a merge that took a file whole from one parent, such as
a clean merge of another unit's branch, still does not stale the record.
