`mutation.py run --since REF` now judges a target whose uncommitted work is all staged, in a private copy of the index (`git checkout-index`) that is removed after the run, so a builder's diff-coverage pass over staged work runs instead of refusing, and the working tree and the index are never written. The copy holds the staged content of every file, so an unstaged edit to a test or helper is not run. A target with unstaged or untracked changes is still refused, and the refusal now names staging the work and re-running with `--since` beside `git worktree add` and commit or stash. The report marks the run isolated in a private copy of the index and names the repository's paths, never the copy's. (BG1768)
