A request refined in part is no longer derived terminal when its children resolve. `refine.py
apply --unrefined AC3,AC4` records the criteria a refine leaves on the request's `Unrefined:`
field and does not seed them onto the story or the epic; an unknown label is refused with
nothing minted. `refine.py add --unrefined` replaces the record with the criteria still left,
and `--unrefined none` clears it. While the record names any criterion, `reconcile.py detect`
reports the request as `request-derivable` naming those criteria and the commands that clear
them, and neither `reconcile.py apply` nor a sprint close derives it. `transition.py set`
refuses the request's successful terminal on the same record, so a hand close is refused too
unless forced. A record that names no label it can read is reported as written and still
blocks. `help/refine.md` documents `--unrefined`.
