The commit-msg hook now refuses a commit that names a unit and stages code when the unit's
`changelog.d/<ID>.md` is neither staged nor already tracked, in a project that keeps a
`changelog.d/` directory. Before, the pre-commit lane judged only the shape of fragments a
commit staged, so a unit could land with no fragment at all. A subject naming one unit owes that
unit's fragment; a shared commit owes one for each `Refs:` id, and a `Mentions:` id owes none.
A commit that stages only files under `sdlc-studio/` or `changelog.d/`, or whose subject names no
unit, is not asked. `Changelog: none - <reason>` exempts one commit, and a bare `Changelog: none`
exempts nothing. The new `changelog.py required <message-file>` is the check the hook runs, and
`refine apply` now ends each story's `Affects` with its own `changelog.d/<story id>.md` when the
project keeps `changelog.d/`, so a builder who stages exactly the Affects ships the fragment.
