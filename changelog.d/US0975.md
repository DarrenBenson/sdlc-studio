- `migrate` reports where a project's own docs still name retired v5 surface. Each line of the
  project's markdown (the files git tracks, or every `.md` outside a git work tree), outside
  `sdlc-studio/`, any installed skill copy and `CHANGELOG.md`, that names a retired verb, flag,
  config key, check id or phrase in a clause not saying it is retired is listed under Needs a
  human as `file:line` with each retired name; the file is never rewritten. The scanner ships as
  `scripts/lib/retired_surface.py`, deriving verbs, keys and check ids from the shipped
  registries and reading retired flags from a CHANGELOG only when one is present, and this
  repository's doc tests import it rather than keeping a second list (US0975).
