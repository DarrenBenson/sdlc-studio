- verify_ac.py revert-check reverts a unit's declared production files to the run's base ref, re-runs that unit's own Verify: selectors, and REFUSES when every measurable criterion stays green - a test that passes without the change never reached it. Green is the refusal, reported per criterion and decided per unit: one criterion going red proves the tests reach the change. Three declared classes are exempt, because five criteria in one six-unit batch legitimately stay green on a production-only revert - a well-formed unnameable plan row, a reasoned Revert-check-exempt field, and a criterion whose plan row names only test code. A selector that resolves to nothing is reported UNRESOLVED and never counted red, since counting it would manufacture a false pass.
