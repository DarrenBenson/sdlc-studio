- **Filed, not fixed: the pre-push boundary gate runs no boundary-only test.** `boundary.py`
  tells an author that a marked test `runs in FULL at every boundary ... so every push, release,
  close and CI run executes it`. Measured against the push path, that is false: `.githooks/pre-push`
  runs `gate.py --boundary push`, whose 23 lanes are the artefact and doc checks plus
  release-rehearsal, revert-check and module-alone - and none of them is a suite lane.
  `SDLC_STUDIO_BOUNDARY_SUITE` is exported by `tools/run-suite.sh` and by CI, and by nothing the
  hook invokes, so `module-alone`'s unittest runs skip every marked test. The deferral the marker
  sells - that a marked test reaches push before it reaches anyone else - does not happen. It is
  recorded here because the fix is a real trade, not a patch: either the push pays the suite's
  wall clock with the marker set, or the docstring stops promising something the gate does not
  do.
