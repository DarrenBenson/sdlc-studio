<!-- section: Fixed -->

`validate.py personas` now warns on a persona card's title and on each section that still
holds an unfilled `{{...}}` template slot, naming the card and the section (`persona-section`),
so a byte-for-byte copy of `persona-template.md` no longer passes as "personas look
well-formed." A slot is a line whose value is a placeholder and nothing else, including a
table cell, a numbered item and a placeholder wrapped over lines; prose that mentions `{{name}}`
syntax and a slot inside a fenced block are not read as one. A Cast role cell that is still a
slot, such as the template's list of all six roles, now declares no role: the missing-cast-role
warning fires and the card is no longer counted as a Primary. An Interface cell that is still a
slot declares no Interface either, so two Primaries that both kept the template's cell draw the
one-Primary warning rather than the shared-Interface error; a real shared Interface still
errors. The check stays advisory: every new finding is a warning and the exit code is unchanged
for a card set that drew no error before. `status.py` no longer counts a persona card whose
title is still the template's slot, so a project whose only card is a copy of the template
reads `personas=no`; a card with a filled title still counts. The persona reference's rule table
and its paragraph on checking a persona now describe both readings.
