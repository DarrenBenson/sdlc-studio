# Support

SDLC Studio is maintained in spare time. This page says what help there is, where to ask for
it, and what falls outside it.

## What support exists

- **Documentation.** [The README](README.md) gives an overview, [the install guide](docs/INSTALL.md)
  covers installing, updating and troubleshooting, and [the skill's command reference](.claude/skills/sdlc-studio/SKILL.md)
  covers every command. Once installed, `/sdlc-studio help` lists the commands and
  `/sdlc-studio status` shows where a project stands.
- **Engineering leaders.** [SDLC Studio for engineering leaders](docs/engineering-leaders.md)
  covers change approval, separation of duties, the signed report and cost.
- **Known issues.** [Known issues](docs/known-issues.md) lists the defects a release ships with,
  and [the changelog](CHANGELOG.md) records what each release changed.
- **Help from the maintainer** through GitHub issues, on a best-effort basis. There is no
  promised response time.
- **Security reports** are handled under [the security policy](SECURITY.md), which sets its own
  response timeline.

## Where to ask

Ask in the repository's [GitHub issues](https://github.com/DarrenBenson/sdlc-studio/issues).

1. Search open and closed issues first, in case your question has already been answered.
2. Report a bug with the
   [bug report form](https://github.com/DarrenBenson/sdlc-studio/issues/new?template=bug_report.md),
   which asks for the steps to reproduce it, what you expected, what happened and your
   environment.
3. Suggest a change with the
   [feature request form](https://github.com/DarrenBenson/sdlc-studio/issues/new?template=feature_request.md),
   which asks for the problem, the change you propose and the alternatives you considered.
4. Report a security vulnerability as [the security policy](SECURITY.md) describes, and keep
   anything sensitive out of a public issue.

## What is not supported

- Paid support, a service level or a guaranteed response time.
- Any route other than GitHub issues and the security policy. There is no other place to ask.
- Anything outside SDLC Studio itself: your project's own code, and the coding agent you run
  the skill in, which its own vendor supports.

## Contributing

To change SDLC Studio rather than ask about it, read [the contributing guide](CONTRIBUTING.md).
