# Gate lanes that FAIL on a freshly migrated v4-era project, each with the artefact that will
# clear it and what the lane will say once it is cleared.
#
# This file is the honest statement of a known gap in the upgrade path. `rehearse-release.sh
# upgrade` reddens in BOTH directions against it: a lane failing that is not recorded here
# blocks, and a lane recorded here that starts passing blocks too - because a baseline that only
# ever tolerates is one that never empties, and an entry nobody is forced to remove is an
# exemption that outlives its reason.
#
# Format: lane|clearing artefact|what the lane says once cleared
#
conformance|CR0497|exempt (pre-adoption) once migrate records a conformance.adopt_after cutoff for the project's pre-v5 history, so the corpus is judged from adoption forward rather than retrospectively
reconcile|CR0497|0 drift item(s) once the upgrade runs reconcile as part of the deterministic set rather than leaving it to the operator to discover
index-derived|CR0497|indexes are derived output, for the same reason - the indexes are regenerated by the reconcile the upgrade should be running
